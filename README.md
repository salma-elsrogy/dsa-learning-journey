# Data Structures and Algorithms — Learning Journey

Welcome to my Data Structures and Algorithms learning journey!

This repository documents my progress in learning algorithmic problem-solving using C++. It focuses not only on implementing solutions, but also on understanding the reasoning, exploring different approaches, and learning from each problem.

## Goals

- Build strong problem-solving skills.
- Understand algorithms beyond their implementation.
- Analyze time and space complexity.
- Practice writing efficient and reliable code.
- Develop a solid foundation in Computer Science.

## Course

**Algorithmic Toolbox — University of California San Diego**

## Language

- C++

## Repository Structure

| Folder | Description |
|---|---|
| `Algorithmic-Toolbox/` | Solutions and learning notes for problems from the course. |

Each problem has its own folder containing the solution, problem-solving notes, and test cases.

## Problem-Solving Approach

For each problem, I aim to document:

1. Understanding the problem and its constraints.
2. Developing an initial brute-force approach.
3. Exploring and deriving an optimized solution.
4. Understanding why the algorithm works.
5. Analyzing time and space complexity.
6. Testing edge cases and handling potential issues.

## Learning Philosophy

The goal is not simply to collect accepted solutions, but to build a deeper understanding of algorithms, problem-solving techniques, and the reasoning behind implementation decisions.

This repository will be continuously updated as I progress through the course.
